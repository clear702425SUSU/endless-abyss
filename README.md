# 無盡深淵：迷宮紀元 V4

中西融合奇幻風格的繁體中文單機地下城 RPG。

## 遊玩

開啟 `index.html` 即可在手機或桌面瀏覽器遊玩。手機使用畫面方向鍵，桌面使用方向鍵或 WASD。

## 功能

- 六大職業：戰士、法師、盜賊、遊俠、聖騎士、死靈術士，各三種獨有技能。
- 隨機迷宮、逐層深入、戰爭迷霧、寶箱、陷阱與泉水。
- 怪物戰鬥、每五層守關 Boss、經驗與升級。
- 隨機裝備、藥水、金幣與循環委託。
- 瀏覽器 localStorage 自動儲存；不同裝置不會同步存檔。

## 部署 GitHub Pages

Repository → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。

預計網址：https://clear702425SUSU.github.io/endless-abyss/

## 開發備註

V4 為可遊玩原型，使用 CSS 與 Emoji 作為暫時美術，尚無正式人物插畫、完整故事任務、跨裝置雲端存檔或多人遊戲。遊戲平衡與跨瀏覽器相容性仍需測試。
